## این پروژه چیست؟

اگر ویدیو تولید می‌کنید — آموزشی، پادکست، محتوای شبکه‌های اجتماعی — می‌دانید که «تولید محتوا» فقط فیلم‌برداری نیست. باید صدا را استخراج کنید، آن را به متن تبدیل کنید، متن را ویرایش یا ترجمه کنید، زیرنویس حرفه‌ای بسازید و شاید هم نسخه صوتی از متن تهیه کنید. معمولاً این کار یعنی پرش بین چند ابزار مختلف، چند سرویس آنلاین پولی، و از دست دادن فایل‌ها بین مراحل.

این پروژه همه این مراحل را در **یک پلتفرم واحد، کاملاً فارسی و راست‌به‌چپ** کنار هم می‌آورد که **روی سیستم شخصی شما** اجرا می‌شود:

- 🔒 **کاملاً محلی** — هیچ فایلی به هیچ سروری آپلود نمی‌شود، مگر خود شما آن را برای پردازش هوش مصنوعی ارسال کنید.
- 🆓 **بدون هزینه اشتراک** — پلتفرم رایگان است؛ فقط برای فراخوانی هوش مصنوعی از حساب خودتان (Claude یا Codex) استفاده می‌کند.
- 🚫 **بدون ورود به حساب کاربری** — یک برنامه شخصی روی کامپیوتر شماست، نه یک سرویس چندکاربره.
- 🇮🇷 **کاملاً فارسی** — رابط کاربری، پیام‌های خطا، و حتی موتور تشخیص گفتار به‌طور ویژه برای فارسی بهینه شده‌اند.
- 🧩 **قابل‌توسعه** — معماری آن از ابتدا برای افزودن ارائه‌دهندگان هوش مصنوعی، موتورهای جدید و ویژگی‌های آینده طراحی شده است.

## ✨ ویژگی‌ها

### ۱. استخراج صدا از ویدیو 🎧

فایل ویدئویی را انتخاب کنید (از هر پوشه‌ای روی سیستم شما، بدون نیاز به آپلود) و صدای آن با کیفیت بهینه‌شده برای تشخیص گفتار استخراج می‌شود — نه بیشترین کیفیت، بلکه **کمترین حجم ممکن با دقت کافی برای تبدیل به متن**. سه پیش‌تنظیم در دسترس است (Opus، MP3، WAV) و فایل اصلی هرگز تغییر نمی‌کند.

### ۲. تبدیل گفتار به متن 📝

یک موتور تشخیص گفتار محلی (Whisper) که کاملاً آفلاین کار می‌کند، صدا را به متن با زمان‌بندی دقیق تبدیل می‌کند — این زمان‌بندی همان چیزی است که بعداً پایه ساخت زیرنویس می‌شود. سپس در صورت تمایل، هوش مصنوعی متن را جمله‌به‌جمله بازبینی می‌کند تا نقطه‌گذاری و املا اصلاح شود، بدون آنکه معنا یا لحن گفتار تغییر کند.

### ۳ و ۴. ویرایش و ترجمه متن با هوش مصنوعی ✍️

متن خود را ویرایش کنید، به هوش مصنوعی بسپارید، نتیجه را در کنار متن اصلی مشاهده کنید و فقط در صورت تأیید، آن را اعمال کنید. **هوش مصنوعی هرگز به‌طور خودکار متن شما را جایگزین نمی‌کند** — همیشه یک مرحله بررسی و تأیید وجود دارد. ترجمه بین فارسی و انگلیسی (و قابل گسترش به زبان‌های دیگر) و امکان نوشتن دستور دلخواه برای هوش مصنوعی نیز پشتیبانی می‌شود.

### ۵. ساخت، ویرایش و رندر زیرنویس 🎞️

یک ویرایشگر زیرنویس حرفه‌ای با تایم‌لاین قابل کشیدن‌و‌رهاکردن:

- ساخت خودکار زیرنویس از رونوشت، با زمان‌بندی واقعی اندازه‌گیری‌شده از صدا
- ویرایش متن، زمان شروع/پایان، تقسیم و ادغام قطعه‌ها با درگ‌ودراپ
- سفارشی‌سازی کامل ظاهر (فونت، رنگ، پس‌زمینه، موقعیت) با پیش‌نمایش زنده روی ویدیو
- رندر نهایی زیرنویس روی ویدیو با FFmpeg — همیشه در یک فایل جدید، بدون تغییر ویدیوی اصلی
- خروجی با فرمت‌های SRT، WebVTT و ASS

### ۶. تبدیل متن به گفتار 🔊

متن را به گفتار طبیعی تبدیل کنید، همراه با **مکث‌های دقیق و قابل‌تنظیم** بین جمله‌ها (نه به‌صورت نشانه‌گذاری متنی، بلکه به‌صورت بخش‌های مجزا که می‌توانید جابه‌جا کنید). صداهای طبیعی فارسی از طریق سرویس عصبی مایکروسافت در دسترس است، به‌علاوه یک گزینه کاملاً آفلاین (SAPI ویندوز) برای زمانی که به اینترنت دسترسی ندارید.

### 🖥️ کنسول هوش مصنوعی و پایش لحظه‌ای

هر عملیاتی که روی سیستم یا از طریق هوش مصنوعی اجرا می‌شود، در یک کنسول زنده قابل مشاهده است — دقیقاً می‌بینید چه دستوری اجرا می‌شود و چه پاسخی برمی‌گردد. اگر از صفحه‌ای که یک وظیفه طولانی (مثل تبدیل گفتار به متن یا رندر ویدیو) در حال اجراست خارج شوید، با بازگشت به همان صفحه روند پیشرفت را دقیقاً از همان‌جا ادامه می‌بینید.

## 🤖 هوش مصنوعی: انتخاب ارائه‌دهنده و مدل

این پلتفرم به‌جای وابستگی به یک سرویس هوش مصنوعی خاص، از یک **معماری مستقل از ارائه‌دهنده** استفاده می‌کند. در حال حاضر دو ارائه‌دهنده به‌صورت واقعی پشتیبانی می‌شوند و هر دو از طریق ابزار خط‌فرمان محلی خودشان اجرا می‌شوند (نه از طریق کلید API مستقیم):

| ارائه‌دهنده | ابزار موردنیاز | نصب |
|---|---|---|
| **Claude** (Anthropic) | Claude CLI | راهنمای رسمی: [claude.com/claude-code](https://claude.com/claude-code) |
| **OpenAI Codex** | Codex CLI | `npm install -g @openai/codex` سپس `codex login` |

از صفحه **تنظیمات ← هوش مصنوعی** می‌توانید:

- ✅ ببینید کدام ارائه‌دهنده در دسترس است (نصب شده و وارد حساب شده)
- ✅ ارائه‌دهنده پیش‌فرض را انتخاب کنید — این انتخاب بلافاصله در تمام صفحات برنامه اعمال می‌شود
- ✅ مسیر هر ابزار خط‌فرمان را به‌صورت دستی وارد کنید (در صورتی که به‌طور خودکار شناسایی نشود)
- ✅ مدل پیش‌فرض یا مدل اختصاصی برای هر نوع کار (ویرایش، ترجمه، زیرنویس و...) را تنظیم کنید

برای هر کار، پلتفرم یک **مدل پیشنهادی** به همراه دلیل انتخاب (به فارسی) نمایش می‌دهد، اما همیشه می‌توانید آن را به‌صورت دستی تغییر دهید. نصب حداقل یکی از این دو ابزار برای استفاده از ویژگی‌های ویرایش متن، ترجمه و بازبینی رونوشت **الزامی** است.

> فقط به یکی از این دو ابزار نیاز دارید، نه هر دو. اگر فقط از یکی استفاده می‌کنید، دیگری را نادیده بگیرید.

## 📋 پیش‌نیازها

| ابزار | ضروری؟ | یادداشت |
|---|---|---|
| **ویندوز ۱۰ یا ۱۱** | ✅ الزامی | این پلتفرم مخصوص ویندوز طراحی شده است |
| **[Node.js](https://nodejs.org/)** نسخه ۲۰ به بالا | ✅ الزامی | برای ساخت رابط کاربری |
| **[uv](https://docs.astral.sh/uv/)** | ⚙️ خودکار نصب می‌شود | مدیریت محیط پایتون؛ نیازی به نصب پایتون به‌صورت جداگانه نیست |
| **[Claude CLI](https://claude.com/claude-code)** یا **[Codex CLI](https://www.npmjs.com/package/@openai/codex)** | ✅ حداقل یکی الزامی | برای ویژگی‌های ویرایش متن، ترجمه و بازبینی رونوشت |
| **FFmpeg** | ⚙️ خودکار نصب می‌شود | برای استخراج صدا و رندر ویدیو؛ نسخه ایستا به‌طور خودکار دانلود می‌شود |

پایتون سیستمی لازم نیست — ابزار `uv` یک نسخه پایتون ۳.۱۲ ایزوله و پین‌شده فراهم می‌کند که با بقیه سیستم شما تداخلی ندارد.

## 🚀 نصب و راه‌اندازی

### گام ۱: دریافت پروژه

```powershell
git clone <آدرس مخزن>
cd ContentCreatorApp
```

### گام ۲: اجرای اسکریپت نصب

```powershell
.\scripts\setup.ps1
```

این اسکریپت به‌صورت خودکار:

1. در صورت نبودن، `uv` (مدیریت محیط پایتون) را نصب می‌کند
2. یک محیط مجازی پایتون ۳.۱۲ برای بک‌اند می‌سازد و وابستگی‌ها را نصب می‌کند
3. موتور تبدیل گفتار به متن (Whisper محلی) را نصب می‌کند
4. یک نسخه ایستای FFmpeg را در پوشه `bin\ffmpeg\` دانلود می‌کند
5. وابستگی‌های رابط کاربری را نصب و نسخه نهایی آن را می‌سازد

> اگر نمی‌خواهید موتور تشخیص گفتار (حدود ۱.۵ گیگابایت برای بهترین دقت فارسی) هم‌اکنون دانلود شود، از `.\scripts\setup.ps1 -SkipAsr` استفاده کنید و بعداً با `.\scripts\install_asr.ps1` آن را نصب کنید.

### گام ۳: نصب حداقل یک ابزار هوش مصنوعی

```powershell
# گزینه ۱: Claude CLI - طبق راهنمای رسمی claude.com/claude-code نصب کنید، سپس:
claude login

# گزینه ۲: Codex CLI
npm install -g @openai/codex
codex login
```

### گام ۴: اجرای برنامه

```powershell
.\start.bat
```

مرورگر شما به‌طور خودکار باز می‌شود و برنامه آماده استفاده است 🎉

## ⚙️ پیکربندی

تمام تنظیمات از داخل برنامه (صفحه **تنظیمات**) قابل تغییر هستند و بلافاصله اعمال می‌شوند — نیازی به راه‌اندازی مجدد نیست:

| بخش تنظیمات | شامل |
|---|---|
| 🗂️ **عمومی** | پوشه کارگاه، محدودیت حجم فایل ورودی، پوسته (روشن/تاریک) |
| 🤖 **هوش مصنوعی** | ارائه‌دهنده فعال، مسیر ابزارهای خط‌فرمان، مدل پیش‌فرض هر کار |
| 🎙️ **تبدیل گفتار به متن** | موتور، اندازه مدل، فیلتر سکوت، بازبینی خودکار با هوش مصنوعی |
| 🎬 **رسانه** | مسیر FFmpeg، کیفیت پیش‌فرض صدا و رندر ویدیو |
| 💬 **زیرنویس** | فونت، رنگ، موقعیت، محدودیت طول قطعه‌ها، فرمت خروجی |
| 🔊 **صدا** | زبان و صدای پیش‌فرض، سرعت، زیروبمی، فرمت خروجی |

## 🛠️ عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| «FFmpeg پیدا نشد» | `.\scripts\setup.ps1` را دوباره اجرا کنید یا مسیر آن را در تنظیمات وارد کنید |
| «Claude CLI پیدا نشد» یا «Codex CLI پیدا نشد» | نصب و ورود به حساب را با اجرای `claude` یا `codex login status` در ترمینال بررسی کنید |
| «ارائه‌دهنده انتخاب‌شده در دسترس نیست» | از صفحه تنظیمات، ارائه‌دهنده دیگری انتخاب کنید یا وضعیت ورود به حساب را بررسی کنید |
| «موتور تبدیل گفتار به متن نصب نشده» | `.\scripts\install_asr.ps1` را اجرا کنید |
| صفحه اصلی خالی یا خطای ۵۰۳ نشان می‌دهد | در پوشه `frontend`: `npm install` سپس `npm run build` |
| درگاه (port) در دسترس نیست | ویندوز محدوده‌هایی از پورت‌ها را برای Hyper-V رزرو می‌کند؛ برنامه به‌طور خودکار پورت آزاد بعدی را پیدا می‌کند |

جزئیات فنی کامل همیشه در فایل `logs\app.log` ثبت می‌شود.
